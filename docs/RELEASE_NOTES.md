OhPorta 1.7 for Android 11 and newer, created by Luis Pinto - 2026.

- Twelve animal avatars replace initial-based user circles. Artwork is bundled locally; avatar assignment stays consistent with the numeric user ID and requires no external avatar service.
- The root README shows only English screenshots. European Portuguese captures are available separately, including the apartment actions sheet.
- English and European Portuguese interfaces, a fixed weekday selector, and five visible access events with scrolling inside the history list.
- No server address is built in. Configure your own compatible backend and token in Settings.
- Fingerprint APK: strong biometric confirmation with device PIN/pattern/password fallback.
- PIN APK: device PIN, pattern, or password without a fingerprint prompt.

Animal artwork is derived from Twemoji 14.0.2 by Twitter and contributors, CC BY 4.0. See `docs/THIRD_PARTY_NOTICES.md`. SHA-256 checksums accompany both APKs.

Both APKs use `com.xsoulp.ohporta` and the same signing identity. Installing one over a compatible OhPorta installation preserves settings. These are sideload builds using debug signing.
